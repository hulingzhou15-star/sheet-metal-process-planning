# 工序内同时执行与三维状态设计

2026-11-02 用户确认：同一道工序内的所有动作同时成形。

后续状态检查以一道工序的动作集合为单位，建立共同的状态变化。不得按动作编号、Excel 行顺序或逐个折弯的任意顺序模拟同序动作。不同工序仍按 Station.order 推进。

同时执行表示需要联合考虑运动：同序的折弯、拉包等结构都随本序过程变化，干涉检查应比较它们在同一过程参数下的位置。不得只让一个动作运动、将其它同序动作一律冻结在工序开始状态。

具体的位移、转角和局部变形轨迹仍需来源支持。用户的同时执行约定不提供这些轨迹，也不意味着所有折弯转角相同、匀速变化，或可以将曲线折弯、拉包视为绕直线的刚体转动。

该确认保存在 configs/process_state_assumptions_v01.json。当前只是后续三维检查的设计事实；三维状态求解、运动干涉和工具可达性检查尚未实现。既有候选分配与 H1–H7 不因此新增一条硬约束。

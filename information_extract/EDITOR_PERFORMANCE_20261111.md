# 特征录入页性能优化 · 2026-11-11

仅改前端调度及 DOM 更新，未降低矢量精度、采样图纸、删除来源或改动人工数据。

实际定位：每次 pointermove 都执行坐标转换、遍历全图 hit-test、更新坐标文本；切换动作反复重建整个动作列表。优化为 requestAnimationFrame 合并鼠标移动与滚轮事件；pointerup 前处理最后移动，防止框选/拖动丢失终点；累计滚轮缩放量并约束范围，全图/聚焦清除待执行缩放。窗口失焦、指针取消及离开时清理待处理事件。列表内容未变化时复用节点，仅切换当前状态；列表点击实时查当前项目，避免撤销/导入后引用旧对象。图元 class 没变化时不重复写 DOM。

同机无头 Edge 集中事件基准（不是实际屏幕帧率或普遍响应保证）：P002 1000 次移动约 85.8→5.7 ms，20 次切换 renderList 累计 89.6→8.9 ms；P004 对应约 88.9→10.1 ms、38.0→14.2 ms。1000 次同帧移动仅需一次末位置命中检测。原始结果 outputs/editor_perf_before.json、editor_perf_after.json；入口 tests/benchmark_editor_browser.mjs。

验证：24 项前端及 42 项 DOM 回归通过；P002/P004 浏览器确认列表节点保留、10 次滚轮累计倍率准确、拖动终点稳定、框选/撤销正确，项目内存数据不变；三件录入页原按钮 smoke 通过。doctor 108 保护输入通过。脚本 tests/test_editor_motion_browser.mjs，结果 outputs/editor_motion_qa.json。未运行全仓测试或测量用户现有浏览器的 GPU/屏幕帧率；不能保证消除所有设备相关卡顿。

服务返回前端资源不缓存，刷新录入页即可生效，不需重启后台。没有强制刷新用户已有标签页。所有修改未提交/推送。

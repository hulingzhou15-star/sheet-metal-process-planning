# H6 停用与 P1 替代检查

## 当前结论

**独立新分配入口已停用 H6，保留 H1–H5、H7。** 冻结 `src/constraints` 与旧复现入口没有改写。新入口不消费原始 Sheet5；P1 的新物理优劣评分尚未标定，不能把“无交叠”或微小指标差异直接转成罚分。

找到一条有实测支持的过渡路线：用几何材料连接树推导每个折弯带动的材料域，以实体体积替代人工影响区面积作为大小代理。P001 的 59 个折弯在该代理下，**1451 个可比较对及其大小方向全部与旧 P1 一致**，32 个对照分配的反向对数与比例也全部一致。这是摆脱人工影响区输入的证据，尚不是证明旧“小先大后”偏好正确或曲线折弯已可通用。

## H6 实际停用位置

`three_d/allocation_policy.py` 提供 `load_context`、`AllocationContext`、`AllocationEngine` 与完整单折弯改序枚举。读取原 Sheet1 事实列、Sheet2、Sheet3、Sheet4；先在内存 XLSX 包中移除其它工作表，再提供一个只有表头、没有任何原数据的 Sheet5 兼容表，以复用冻结的事实校验器。原始 Sheet5 XML 不读取；专家列不参与解析。原工作簿不修改。

新 Context 禁止传入影响区记录；新 Engine 拒绝旧 Context，结果显式列出启用 H1/H2/H3/H4/H5/H7、停用 H6。H6 从先后关系集合及传递可达关系中消失，而非仅隐藏报告计数。旧 P1 仅在新方案生成完成后，由离线比较代码读取；不用于生成或筛选。

P001 实际关系数量：H3=34、H4=46、H6=0、H7=153。32 条旧 H6 全被 H7 直接覆盖，因此唯一有向先后对不变。354 种单折弯改序的可行性判断逐一与旧引擎对照，全部一致；31 合法＋基准=32。P2 按新关系重新计算，32 方案的值都与旧值一致，没有沿用旧上下界缓存或重分配权重。

范围：这是新流程的可执行入口和受控改序实验，尚未替换冻结的全候选生成 CLI。新的 CP-SAT 全空间生成入口也尚未接入；不得宣称整个项目所有历史命令已删除 H6。当前 P001 沿用被冻结业务事实中的224动作及固定切边事实；没有修改编辑器或其它零件。

## P1 可以怎样替代

| 路线 | 本轮实测 | 判断 |
|---|---|---|
| 二值自干涉 | 前轮32方案全无交叠 | 这批样本没有排序区分能力 |
| 全程最小非连接间隙 | 本轮32方案均约0.2mm | 被相同局部区域对主导，不能直接当全方案P1 |
| 同时接近的区域对数 | 0.4/0.8/1.6mm下最大均为2对；4mm下为15–17对 | 对观测尺度敏感，无安全阈值或优劣依据，不直接赋权 |
| 体积加权质心路程 | 全部约18.6862975mm | 在此固定H7/材料模型下几乎不变，不能直接排序 |
| 同时运动材料体积峰值比例 | 36.4051%–36.5299% | 有微小变化，但不是冲压力、加工时间或已验证难度 |
| 几何带动量大小代理 | 59域，1451比较对方向与旧P1一致 | 可作为替换人工面积输入的过渡候选，保留旧偏好假设 |
| 工具/模具可达性、加工余量 | 工具形状及轨迹等未接入 | 可作为更直接的未来工艺指标，当前不能编造数据评分 |

最小间隙见证对 `P330_334` / `P401_409`，对应材料树子板关联 O017 / O154；不能因其约0.2mm就判不可加工。这里的0.2mm为当前实体模型距离，不是制造公差或新增安全标准。

间隙观测只纳入本序有相对运动且非直接相邻的刚性区域对；目的是避免固有连接或共同刚性运动淹没观测。**该排除只用于此软指标探索，不能移植到碰撞检查中免检相邻板。** 每序0到1共25点，同序共享进度，使用进入态材料；局部成形统一端态切换，不假设先冲后折。32方案共2400个观测状态，1631次实际距离内核调用，其余按保守包围盒或确定性缓存复用；无计算未决，总循环254.20秒。距离采样和模型均有覆盖限制。

## 几何代理的定义与结果意义

对于折弯 i，由几何连接树的 child 板面向下遍历材料域，取其刚性实体体积之和 V_i。使用全部去料及局部成形完成后的共同材料作为固定参考；这不等于各序实际质量，且未包括有限宽折弯带。

在不受已确认硬先后限制的两个折弯间，沿用原1.15显著比判断大小；较大的 V_i 被安排得更早记一个反向对，同序不计。取反向对数/可比较对数。这保持了旧“小先大后”的假设，仅替换代理量的来源。没有回填 Sheet5、没有把材料域伪装为旧人工区域、没有修改正式评分。

离线比较发现：新旧可比较对与方向完全一致。因此，在本件这59个折弯、当前固定材料参考及1.15阈值下，两者使用同一反向计数公式会给出相同值；这不只依赖32方案的偶然同分。仍须分别验证其它零件、阈值附近的大小关系及曲线折弯材料域识别。P002曲线折弯的局部逐序模型尚未接入本实验，不能写成已经解决。

**建议推进顺序**：先把几何带动量代理作为独立 P1 候选版本，在其它零件验证其材料域与排序行为，达到不依赖人工影响区的目的；若进一步希望替换“小先大后”本身，则需独立工艺依据，围绕每个动作的局部过程间隙/工具可达性建立验证案例。不能仅为了拉开分数而加入任意权重。当前无专家真值用于拟合、无自动制造优劣标签，GNN也未实现。

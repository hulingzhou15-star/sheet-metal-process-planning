## 1. 目标与当前输入

以 P001 的二维展开 DXF 为样本，开发一个可交互的本地 HTML 标注工具。用户在图上多选原始几何、创建加工动作、填写属性和关系、确认折弯影响区；脚本保存精确几何和来源，导出当前候选生成器需要的数据。

当前输入为本目录已有的 `Plotview 1.dxf`，保持原位、只读：

- 文件大小：432,278 bytes。
- SHA-256：`180a7761767ed99402df43516d71403b61fa1dcc725363a190aa4e51d16365ef`。
- 本次实测：INSUNITS=4（mm）；目标块 `Plotview 1`；一处插入实例；旋转 270°、单位比例。
- 解析得到 1,317 个原始几何对象，拆为 2,253 个基础片段：1,813 LINE、280 ARC、160 CIRCLE。
- 上述数量不是加工动作数，不能作为自动分组答案。

旧代码复用依据见 [LEGACY_REUSE_REVIEW.md](LEGACY_REUSE_REVIEW.md)。代码、测试、配置、缓存、临时文件、项目保存、截图、导出表格和报告等所有新增模块文件均置于本目录。根项目源码、配置、原始工作簿、Graph0/1/2、候选、reference 和旧结果保持原有内容。

## 2. 已确定的人机分工

| 内容 | 用户负责 | 程序负责 |
| --- | --- | --- |
| 动作识别 | 决定哪些几何属于同一动作 | 提供精确选择、高亮和来源记录 |
| 动作属性 | 名称、编号、父动作、类型、表面侧 | 录入、编辑、引用更新和校验 |
| 其它工艺关系 | 预孔/翻孔配对、明确前置关系 | process group 与 predecessor 整理 |
| 普通几何 | 选择圆或组成轮廓的片段 | 提取坐标、半径、有符号角度、seq |
| 折弯 | 多选属于同一折弯的双侧分段，确认中线 | 平行/对应检查、中线计算、来源追溯 |
| 折桥 | 确认外围范围及简化表示 | 输出 footprint，收纳内部辅助线 |
| 折弯影响区 | 确认影响侧、边界、父影响区或无父级 | 计算长度/深度/面积并生成 Sheet5 |
| 工序信息 | 填写 Sheet3、Sheet4 | 导入、保留、校验及合并导出 |
| 数据完成情况 | 解决标注歧义、确认遗漏原因 | 给出缺项、错误和可进入生成器的状态 |

不把动作数量、图层颜色、虚线样式、文字最近距离、CAD 树排列顺序当成自动工艺识别依据。预期动作数可选填，只用于核对，不强行凑数。第一版不做三维自动识别、完整动作自动分组、自动生成专家答案或模型训练。

## 3. 推荐架构和文件组织

采用 Python DXF/几何/校验服务 + 本地 HTML/SVG/JavaScript 编辑界面。使用本地服务是为了让“保存”确实写入本目录，并统一几何计算和 Excel 导出；不把浏览器下载目录或 localStorage 当作唯一项目存储。

服务仅面向本机，写入路径解析后必须留在本模块目录。页面不依赖外部 CDN。开发时可复用现有运行时，记录实际依赖版本；旧代码正式迁入时只复制需要的核心文件及其测试，保存来源与 SHA，不依赖 Desktop 旧目录运行。

## 4. 数据模型先于界面功能

### 4.1 三层表示

1. **SourceEntity/SourceSegment**：原始 DXF 对象与拆分片段，保存 handle、块插入实例路径、polyline 段号、图层、样式、原始参数、变换和单位。
2. **AnnotatedOperation**：用户创建的动作，保存稳定内部 ID、显示编号、名称、类型、表面侧、父动作、process group、predecessor、多选来源和完成状态。
3. **DerivedGeometry/InfluenceRegion**：Sheet2 几何和 Sheet5 影响区，保存生成方式、参数、来源及确认记录。

一个动作可关联多个来源片段；来源可按实际情况服务多个动作，采用明确绑定，不能假定一对一所有权。原始片段不因派生几何而删除或改坐标。

来源键由源 DXF 指纹、实体 handle、插入实例路径和段号构成；不能用遍历得到的 E000001/CAND000001 作为跨版本稳定身份。项目中区分内部 ID 与用户可编辑编号，重命名时更新关系，不重新分配其它动作身份。加载时源指纹变化应报告不匹配，不能自动猜测重新绑定。

### 4.2 实体处理状态

- 直接绑定：已明确选入动作。
- 区域收纳：被已确认折桥简化区域包含的内部辅助片段。
- 背景/明确忽略：用户确认只作背景或无需动作表达，保存原因。
- 尚未处理：未有任何上述有效处理记录。

底层允许多条关联记录；统计按实体去重。直接绑定优先展示，区域收纳和背景可作辅助标签，不能重复扣减数量。删除动作、修改范围或撤销后重新计算状态，不能留下“已处理”的残余标记。

另列“不支持/被拒绝的源实体”，不能从总量悄悄消失。隐藏图层不等于已处理；未处理数为零也不代表动作清单已经完整。

### 4.3 坐标与精度

- 几何、derived geometry 和 Sheet2/5 使用同一明确材料坐标系；本样本使用已核验的 `Plotview 1` 局部坐标。
- WCS/OCS/块变换、原始单位和显示变换分别保存。
- 270° 熟悉视角为默认显示，点选、框选、坐标查询、缩放、聚焦共享同一正逆映射；不能再把 DXF 自带旋转重复施加到数据。
- 完整精度数值用于运算、保存和正式导出；表格显示小数位可配置，不沿用旧导出实际 round(..., 3) 的做法。
- ARC 保留有符号 sweep_angle，方向反转时端点和扫角同时正确变换；禁止把扫角统一取绝对值。
- 将解析精度、点合并容差、平行判断容差、屏幕点击容差分别配置，不能混同工艺安全距离。既有下游校验容差保持不变。
- 一般缩放/镜像坐标适配必须验证半径与扫角；第一版无法可靠支持的变换明确报告，不混用局部圆心与 WCS 半径。

## 5. 几何编辑行为

### 5.1 普通动作与轮廓

- 点选、多选、框选、增选/减选、清空、撤销/重做；平移手势与选择手势分离。
- 真实曲线命中；密集或重合实体支持查看候选并切换，不能只凭绘制顺序选择。
- LWPOLYLINE 支持按子段选择，也可整条选取；显示虚线短划不制造新实体。
- 圆孔/PRE_PUNCH 使用圆；FLANGING 按确认的同心圆集合表达，不把某个圆自动分配成预孔。
- IRREGULAR_PUNCH 使用用户选择的 LINE/ARC 形成闭合链，检查重复段、断口、分叉、顺序和方向。不能自动加连接线。
- 用户可指定起始段辅助编辑，但导出应遵守 PROJECT_SPEC 的既有起始段及整体逆时针协议，显示规范化结果；不原样导出不兼容顺序，也不修改原始图形。
- 支持无几何动作并记录原因；“暂未绑定”与“已确认无适用几何”分别显示。
- 图中全部轮廓可作背景显示；外轮廓不能自动被当成 TRIM，也不能用于把整件内部实体一律收纳。

### 5.2 折弯：双线、多段与中线

- 用户把同一折弯的两侧多个片段选为一个集合；即使被其它图形分隔，也可创建一个 BEND。
- 程序检查同侧共线、两侧平行、间距和片段对应关系，必要时让用户明确分到 A/B 两侧。
- 对有明确对应关系的双侧几何计算等距中线，间距来自图纸，不写死 0.4 mm 等样本数值。
- 按用户确认的同一折弯覆盖范围生成中线起终点；跨间断的逻辑中线在预览中明确显示。无法唯一确定跨度或配对时保持待确认，不静默延长或吞并其它折弯。
- Sheet2 导出一个 BEND_LINE 片段；保存所有来源、两侧分组、跨度、计算结果与确认状态。
- 已有真实中线可使用“直接采用已选中线”模式；不能把只有一侧的边界默认为中线。

验收必须包括用户截图中“四处分段、同一折弯”的场景，不能只验证一对连续平行线。

### 5.3 折桥：footprint 与内部实体收纳

- 用户选择并确认外围边界，预览与当前 schema 兼容的 footprint；本阶段以原始材料坐标的轴对齐包围范围表示。
- Sheet2 生成一个 BRIDGE：start 左下、end 右上、center 为对角点中点；内部线段不逐条导出。
- 确认后，对完整位于该确认区域中的、尚未绑定的内部辅助线段自动建立收纳关系；不要求逐条点击。
- 包含判断覆盖完整几何：直线不能只查中点，圆弧不能只查端点。跨出边界的片段不整条收纳；不自动切割原始片段。
- 已属于其它动作的实体保持原关联，界面列出重叠情况；收纳可逐项解除，仍可选择内部实体建立独立动作。
- 自动收纳仅对显式启用的简化区域生效，不对所有闭合图形、零件外轮廓或折弯影响区执行。
- 多区域重叠要保留来源并去重统计；调整/删除区域、撤销/重做后统计正确恢复。
- 斜置或非矩形折桥若无法由现有表示可靠表达，报告表示限制，不能未经确认改成面积更大的框。

### 5.4 折弯影响区

- 从已确认的 BEND_LINE 开始，用户选择影响侧、远边界，并预览整个区域。
- 父影响区由用户明确选择或确认无父级；未填写不等于已确认无父级。
- 在现有水平/竖直区域定义下，自动计算 bend_axis、far_boundary_coord、affected_depth、bend_length、affected_area_proxy。
- Sheet5 绑定唯一 BEND 与 region，校验引用和无环；CAD parent 不自动复制成 region parent，包含关系或面积大小不自动生成 H6。
- 调整中线或影响区之后，派生数据失效并重新计算/确认，避免旧值悄悄导出。
- 本轮不扩展既有 Sheet5 语义；斜折弯、非矩形或无法确定的区域明确列为待解决。

## 6. 导出与当前候选入口的契约

| 表 | 字段或内容 | 处理方式 |
| --- | --- | --- |
| Sheet1 | part_id, operation_id, source_feature_ref, operation_type, surface_side, required_predecessor_ids, cad_parent_operation_id, process_group_id, geometry_id | 来源于用户标注；名称映射 source_feature_ref，内部 ID/来源细节保留项目文件 |
| Sheet2 | part_id, geometry_id, seq, segment_type, start_x/start_y, end_x/end_y, center_x/center_y, radius, sweep_angle | 根据已确认的几何表达生成；无意义字段留空 |
| Sheet3 | part_id, station_id, order, allowed_operation_types | 用户填写，程序校验；不从 reference 反推 |
| Sheet4 | operation_id, fixed_station | 用户填写，沿用固定 TRIM 定义；明确确认无记录时保留空表头 |
| Sheet5 | bend_operation_id, start_x/start_y, end_x/end_y, bend_axis, far_boundary_coord, affected_depth, affected_side, bend_length, affected_area_proxy, influence_region_id, parent_region_id | 由确认后的中线、边界和层级计算 |

无需 expert_station；标准事实输出不带专家答案、评分或候选角色。Sheet3/4 可以在模块生成的草稿工作簿中手填后回传，或从用户提供的表中导入；合并生成新文件，保留用户值和来源，不覆盖原工作簿。

保存项目与导出标准表分开：

- **草稿**：随时保存，缺项允许存在并显示；不能冒充可进入生成器的数据。
- **数据契约通过**：使用 `src.inference.input.load_inference_context` 只读回读导出副本，复用现有事实校验。
- **硬模型检查**：在用户提供 Sheet3/4 后调用现有 H1–H7 可行性接口，分别报告可行、不可行、未决。一次见证求解用于验证可行性，不批量生成候选、不排名。
- **几何/标注覆盖报告**：单独记录未绑定、确认无几何、未确认影响区及不支持实体。旧 loader 能加载，不等于新工具全部标注完成；存在未完成项不标记“完整就绪”。

测试用已有 P001 工作簿只能作为独立只读对照或用户已给定配置，不得把它的几何、动作答案偷偷导入标注结果。也不要求当前 DXF 必然与后续修订过的每一个 P001 几何完全一致；来源差异单列，不回填其它 DXF 伪装为本图提取。

| 导出 | 全精度与空字段、Sheet3/4 保留、事实 loader 回读、专家列不需要、不带编辑器管理字段、原文件哈希不变 |
| 可行性 | 合成可行/冲突事实及当前 P001 事实独立测试，区分 infeasible 与 unknown，不用专家作为可行见证输入 |
| 浏览器 | 创建→编辑→保存→重开→导出全流程；输入框快捷键不误删实体；刷新与未保存状态清楚；控制台无异常 |
| 范围隔离 | 所有新输出与缓存留在 information_extract；审查/开发不改旧代码和根项目冻结数据 |

针对每阶段运行相关检查，失败保留原因，不通过改变原始图纸、根校验规则或旧测试快照来消除失败。

## 9. 已知限制与处理方式

- 仅有特征树显示顺序不够，必须保存显式父编号；未知关系保持未知，不转成先后约束。
- Sheet5 仍需要用户确认影响侧/边界/层级，这些内容不是选择折弯双线就能完全得到。
- P001 采用单位比例、保向局部坐标；其它图纸的坐标/缩放应显式选择与验证，不能沿用隐藏假设。
- 第一版仅可靠处理已支持的 DXF 实体。其它实体列出来源和原因，允许用户回 CAD 处理后另版导入，不伪造几何。
- 旧历史数据有后续替换/修订的来源；本图能否复现全部当前 Sheet2 尚未逐动作验证。
- 工具从图形整理事实，无法验证未被建模的真实生产条件。其“可进入生成器”只指数据与现有规则契约。

首版已经按以上顺序实现。下一步以本工具开展 P001 整件人工标注和试用，记录真实图纸中的选择与表达问题，再作局部改进，不提前扩展全自动特征识别。

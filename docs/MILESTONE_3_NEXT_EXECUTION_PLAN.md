## 1. 当前起点

- 独立 v0.6 入口已有 H1–H7；H7 全量 CAD child 严格先于 parent。
- 新版 P1 排除所有硬先后直接或传递确定的 BEND pair；P2 按唯一有向 pair 计一次；P3 仅 FLANGING。当前权重仍为 0.45、0.20、0.35。
- 折弯方向分量已实现硬可行 K_min/K_max 归一化，但未进入总分或排序。
- k=5 邻近分析已实现诊断，没有邻近硬禁止或 soft penalty。
- 旧生成器仍使用旧规则和 reference。旧候选、盲号、比较顺序与评审包没有更新。
- 新版纯硬可行模型不依赖 reference，但完整无 reference 输入与正式候选生成尚未实现。

## 2. 已能确定的执行步骤

### 步骤 A：建立新批次基线，整理待确认工艺对

1. 对当前工作区保护文件记录新 SHA-256 基线，保留历史 manifest，不重写旧快照。
2. 沿用现有 v0.6 的 H1–H7、P1/P2/P3 定义，不重复实现；继续分别记录计算、评分、生成三个接入状态。
3. 从现有 k=5 诊断导出 FLANGING–IRREGULAR_PUNCH 待审 pair 清单：两个 Operation、来源名称、实际边界距离、双侧邻居排名、当前方案 Station、已有硬路径、来源数据版本。
4. 对 A02/A06/A08 的同序 pair 提供定位；以 O131/O203 验证识别覆盖，但不预先认定所有邻近 pair 都存在干涉。
5. 区分“几何候选关系”和“已确认工艺冲突”。D 只表示两方案都有明显问题，不能自动产生某个 pair 的冲突标签。

验收：清单可回溯到已有几何与方案；不修改 Operation 类型、CAD parent、Graph 边或专家答案。

### 步骤 B：在新版本入口接入选定规则

依赖第 3、4 节用户选择。建议后续规则版本为 v0.7，保留 v0.6 行为。

1. 如选择硬禁止，在独立评估器和 CP-SAT 模型中同步编码 station(A) != station(B)，输出 pair 与证据来源。禁止同序本身不指定先后。
2. 如选择邻近 soft，仅对确认适用的类型和几何 pair 集计算同序比例；不暗中转换成硬过滤。
3. 按选定方式让方向分量真正影响新版本筛选，并报告分量、权重或优先级；不得仅输出诊断后声称已生效。
4. 若新加硬规则，P1 的硬顺序排除范围和 P2 的先后关系集合仍按其原语义处理；单纯 != 不是有向先后，不自动计入 P2。
5. 方向 K_min/K_max 按新版本完整硬可行域重新求精确界；不沿用旧域缓存，不读取 reference。无法证明极值时明确失败。
6. 先做离线 expert 复核。新增规则若与其冲突，列出原始关系与冲突并停止后续结论，不改 reference、不添加隐式例外。正式无 reference 推理入口不设置 expert 前置校验。

### 步骤 C：复核历史方案，验证实际效果

1. 分别报告旧 240 个池候选、60 个 selected 和 13 个盲化评审方案的新可行性与新分量。
2. 对 24 对人工评审给出双方可行性、触发关系及分数变化；不把 D 自动改成 A/B，不改旧答案。
3. 对 A02/A06/A08 输出逐 pair 前后对照：是否仅被记录、是否产生扣分、是否被硬拒绝。明确剩余未建模问题。
4. 将已知 5 项历史快照失败与新增失败分别报告。此前完整测试为 397 项、392 通过、5 失败；新增 v0.6 的 45 项通过。这是历史记录，执行时重新跑测试并记录实际结果。

验收：所选硬 pair 同序时必被评估器和求解器拒绝；软项变化能改变其贡献或对应优先级，但不声称一定改变最终排名；旧输出 hash 不变。

### 步骤 D：接入新的无 reference 候选流程

在规则选择和步骤 B/C 验收完成后进入；本次写计划不启动批量生成。

1. 按既有训练实施流程新增事实输入/校验入口：专家列完整、为空或缺失均能处理，推理决策不消费专家分配。
2. 使用本件事实和已确认新硬规则生成候选；以独立硬约束引擎复核每个结果。
3. 复用不依赖 reference 的候选间分配距离做多样性筛选；不使用专家距离分档、专家 warm start 或专家负载 G1。保留软启发式与多样性选择各自统计。
4. 新评分版本仅服务候选生成/筛选启发式，不是训练标签，也不是训练好的质量模型。模型训练另行实施。
5. 生成数量、预算、种子和筛选比例在该阶段实施前形成明确配置，不静默沿用旧 reference 分档参数。超时、不可行、候选不足分别报告。
6. 同一事实在专家答案删除或替换后，应保持推理输入、目标、约束和派生种子一致；使用确定性测试夹具核验结果，不用原始文件整体 hash 驱动随机决策。

验收：无专家答案可运行；全部输出满足新规则；无候选被误称为已排除所有现实工艺问题。

### 步骤 E：建立新评审批次

新候选池先冻结，再产生独立批次的代表选择、比较对、盲号和可视化。复用已验证的显示能力，但不覆盖旧 24 对及旧盲号。新批次规模和选对配置在生成结果与覆盖统计具备后明确，不把旧 NEAR/MEDIUM/FAR 逻辑带入无 reference 流程。

训练数据同时保留规则版本、生成来源和原始人工标签。新规判为不可行的旧方案单独标记，不能直接混进“合法方案质量比较”的训练集。P001 已参与规则设计，不能作为完全未参与开发的测试零件。

## 3. 待选择一：临近 FLANGING–IRREGULAR_PUNCH 如何处理

本轮建议只讨论该类型组合；不默认扩展到全部 OperationType。不以 CAD parent 必须是 BEND 或名称包含“折弯异形孔”作为必要条件，不新建类型。下面三个方案是替代方案，选择前不启用。

### N1：确认 pair 后硬禁止同序（推荐）

- k=5 用于发现待审对象；专家逐对确认实际不能同序的 pair，进入独立 constraint metadata。
- 对确认 pair 要求不同 Station，不自行确定谁先谁后。未确认对象仍诊断。
- 明确确认的 pair 即使不在 k=5 内也可记录，k=5 不作为硬规则适用性的必要条件。
- 优点：能保证具体已确认冲突不再出现，不把远距离第 5 邻居误当干涉。
- 代价：当前还没有完整确认清单；本方案选择本身不等于确认所有邻近 pair。新零件若需要此规则，必须有推理时可获得的工艺关系 metadata，不能从隐藏专家方案提取。缺失时报告覆盖缺口，不宣称已处理临近冲突。

### N2：k=5 类型 pair 同序软惩罚

- 使用现有全类型 k=5 无向 union，随后筛选 FLANGING–IRREGULAR_PUNCH，去重；不另按某一种类型重新找 5 个近邻。
- c_near = 同 Station 的适用 pair 数 / 全部适用 pair 数；分母为零时 0。
- 优点：无需逐对标注即可在新零件上计算，影响筛选而不产生大量硬不可行。
- 代价：同序仍可能入选；排名邻近不是实际干涉证明，稀疏区距离较远的 pair 也会参与。
- 只使用该方案不能保证消除用户所指出的所有同序现象。

### N3：k=5 加明确几何阈值后硬禁止同序

- 使用与 N2 一致的 pair 构造，再要求真实边界距离 <= d，适用 pair 禁止同序。
- 优点：可自动用于新零件，也能硬性阻止所定义范围内同序。
- 代价：目前没有已确认的 d、单位适用性、板厚/模具依赖及该判定足够性的依据。必须先由工艺依据确定这些内容，再实施；不能从 O131/O203 的约 2.1 直接推出通用阈值。
- k=5 截断可能遗漏阈值内其它 pair；若要求覆盖所有距离 <= d 的 pair，需要另行明确范围调整，不能仍声称覆盖所有近距离对象。

已知边界：当前 expert 有 O041/O073 这一对 k=5 FLANGING–IRREGULAR_PUNCH 同序，距离约 45.119683。不能直接把“全部 k=5 pair 禁止同序”当已确认规则，也不能把 expert 视为永远正确并自动豁免该 pair。

## 4. 待选择二：折弯方向分量如何参与筛选

公式已确定：p_d=(K_d-K_min,d)/(K_max,d-K_min,d)，相等时为 0；只对存在且可调整的方向平均。以下只是接入方式选择，不改变公式。

### D1：加入加权 SoftPenalty（推荐的试验起点）

方向权重暂取 0.15，保持原 P1:P2:P3 的相对比例。该数值是待选择的实验参数，不是经专家数据拟合或证明最优的权重。

| 临近选择 | P1 | P2 | P3 | 方向 | 临近 |
| --- | ---: | ---: | ---: | ---: | ---: |
| N1 或 N3（临近为硬约束） | 0.3825 | 0.1700 | 0.2975 | 0.1500 | 不计软分 |
| N2（临近为软项） | 0.3150 | 0.1400 | 0.2450 | 0.1500 | 0.1500 |

各行总和为 1。两种用途不重复处罚同一项硬禁止。P001 的 P3 为 0 不构成自动重分配权重的理由。不得以 expert 总分最低或拟合 18 个 D 为目标调这些权重。

### D2：方向作为主要启发式，再比较其余软分

按 (c_direction, S_other) 字典序比较，较小优先。若 N1/N3，S_other 为现有 P1–P3 总分；若 N2，建议 S_other=0.3825*c_area+0.17*c_gap+0.2975*c_type+0.15*c_near。

无需方向权重，但隐含“方向任何改善优先于其它软项改善”的强偏好，需明确认可。该优先级用于软启发式筛选部分，不能据此跳过候选多样性要求。它仍不是硬规则，也不保证所有保留候选都达到最小方向分量。

### D3：本轮仍只单独报告

不接入方向排序。若 N1/N3，软总分仍是原三项；若 N2，使用 D2 中 S_other 的四项权重作为待选试验起点。优点是少引入未经验证的偏好；代价是本轮方向分量仍不能改善候选筛选。

三个选项都不新增“必要三个 Station 内负载应如何分配”的偏好。SMOOTH 当前 [3,3] 不受方向项处罚，也不能由此推出其具体负载分布合理。

## 5. 测试与产物要求

- 约束覆盖：H1–H7 回归；新硬规则与求解模型一致；输入 pair 存在性、去重、自配对拒绝、来源可追溯；不可行明确报告。
- 邻近覆盖：O131/O203 无 BEND parent 仍被正确识别；全类型 k=5 后筛选；单向/双向去重；缺几何不发明距离；N1 明确 pair 不受 k 截断；N3 阈值边界测试。
- 评分覆盖：方向不可避免拆分为 0，边界随新硬域更新；所选加权或优先级路径真正使用该分量；无重复硬/软处罚；分量及加权总分范围正确。
- 推理隔离：无 reference 可运行；expert 分配变化不进入推理决策；旧 G1 不被构造。
- 评审覆盖：旧 ID/排序/答案原样保存；新批次不泄露内部映射、reference 身份或软分；截图转录来源单独保留。
- 建议产物：新规则规范与配置、冲突 metadata（如选 N1）、逐 pair 审计、旧方案复核报告、新候选生成审计、新评审批次、完整测试日志和冻结完整性报告。路径使用独立版本目录，不覆盖历史。

# 复现与清理协议

当前支持 Windows、Python 3.12 和 P001 核心复现。输入入口为 configs/project.json。

1. 安装项目环境和 npm 锁定依赖，执行 doctor。
2. 验证 registry/protected_inputs.json：人工输入、候选和冻结算法不变。
3. `reproduce --part P001 --target core` 从 CAD、业务事实、确认参数与冻结方案构建。
4. 对比迁移前独立期望：Graph0/1/2/动态属性、材料拓扑和位姿、224 状态、去料与局部成形、体积和网格数。
5. 运行几何实体见证测试、指定范围干涉、浏览器审核交互和报告生成。

冷重建不得复制现有 outputs，不允许桌面兜底和 Codex 账号环境注入。环境可以重用已安装的项目解释器/依赖，但输入代码必须来自隔离工作区，产物只能写入该工作区。
三维数值比较绝对容差 1e-5，冻结输入/方案/图结构按哈希比较。不要把路径或 JSON 缩进变化当几何变化。

候选重新求解与历史方案重放是不同任务。本命令重放冻结方案，不重新抽样并冒充相同候选。

旧成果归档包必须记录包哈希、原路径、成员大小与哈希，验证后才移除原目录。历史快照测试需要对应档案时显式恢复，不能无声依赖旧工作区。
归档表示可追溯，不表示所有历史脚本已迁成当前接口。新开发使用当前入口和保留集。

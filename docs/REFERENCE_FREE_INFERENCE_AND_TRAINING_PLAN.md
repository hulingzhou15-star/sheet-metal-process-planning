## 1. 最终目标与适用版本

> 新来一个从没见过、也没有专家答案的零件，系统只根据本件数据生成一批合法候选，再由训练好的模型评分排序，推荐 Top-K 给专家。专家方案和专家评审用于训练与离线评价，不能成为正式推理的必要输入。

决策单位始终是完整的 Operation → Station 分配。硬合法表示满足当前已建模规则，不等于已证明全部生产条件成立。

## 3. 正式推理的信息边界

### 3.1 允许输入

- 当前零件的 Operation、Geometry、Station、Station.order 与 capability。
- 已确认的 explicit predecessor、process group、CAD child→parent 关系。
- Sheet4 固定 TRIM、Sheet5 influence region 和 parent 元数据。
- 固定版本规则、邻域配置、生成预算和种子；未来包括训练好的模型及 Top-K 配置。

这些条件必须在新零件推理时可获得。缺失或含糊时报告缺项，不能从专家答案反推。自动邻域来自本件几何，不要求每件手写问题 pair 清单。

事实指纹不包含专家分配、输入路径和文件整体 SHA；文件 SHA 仅作来源审计。专家列完整、空白、缺失或无效均不参与事实决策；Sheet4/5 等必需事实仍需提供。只改专家列不能改变派生种子或生成逻辑。

### 3.2 禁止输入

专家 Operation→Station、专家负载、到专家的距离、专家比较答案、confidence、reason_note、reference 身份、盲号映射、代表选择角色，均不作为正式生成或模型特征。

不使用专家 warm start、默认插入、隐藏 fallback、NEAR/MEDIUM/FAR 专家距离分档或旧专家负载 G1。不要求候选必须不同于专家；独立求得相同分配可以保留，相同与否仅在离线评价中识别。

| 场景 | 专家材料的允许用途 |
| --- | --- |
| 训练零件 | 人工比较监督；专家方案可作为来源单独记录的比较对象，不自动获胜 |
| 内层验证零件 | 对先固定的候选和预测计算指标，选择开发设置；不参与该件生成或模型输入 |
| 外层测试零件 | 预测固定后才读取评价材料；不能返回调参或修改本轮候选 |
| 实际新零件 | 没有专家答案仍可运行；后续反馈进入新版本训练数据 |

## 4. 当前硬约束与软偏好

### 4.1 H1–H7：完整方案硬可行性

| 规则 | 职责 |
| --- | --- |
| H1 | 全部 Operation 完整、唯一地分配到真实 Station |
| H2 | 满足 Station capability |
| H3 | explicit predecessor 严格先于后继 |
| H4 | 同 process group 的 PRE_PUNCH 严格先于 FLANGING |
| H5 | 执行 Sheet4 固定 TRIM |
| H6 | 已确认 child region 对应 BEND 严格先于 parent BEND |
| H7 | 有效 CAD child Operation 严格先于 parent Operation |

先后使用 Station.order，gap 使用按 order 排序后的连续 rank。H7 的制造方向不改变冻结 CAD_PARENT 图边语义。候选输出后独立复核，模型不能放行硬违规方案。

### 4.2 P5：生成阶段最高优先级的邻域软偏好

当前按字典序比较 (P5, S_secondary)，均越小越好。P5 不与其它分量做可抵消的加权和；新入口也不再叠加旧 N1 逐对不同序条件。

适用外部 PRIORITY 关系为：

- FLANGING–IRREGULAR_PUNCH：翻孔侧 PRIORITY 触发。
- BEND–FLANGING、BEND–IRREGULAR_PUNCH：适用主动侧 PRIORITY 触发。
- 排除内部预孔/翻孔关系、已有硬先后直接或传递路径、合法工序域无交集；无向 pair 去重。
- 同类动作、简单圆孔/预孔、其它未启用组合不自动加罚；EXTENDED 仅观察。

每个非空细分类型计算“同序 pair 数 / 固定有效 pair 数”，再对类型等权平均。分母由事实和政策确定，不根据候选或专家分配改变。没有覆盖不代表没有风险。

几何范围沿用 configs/neighborhood_v01.json：相关圆形特征使用 3 倍记录直径范围；BEND–IRREGULAR 使用真实曲线距离 10 个源坐标单位；相同 anchor/family/metric 内首个有限正距离 3 倍跳变划分 PRIORITY/EXTENDED。不强求 k=5，不改变 Graph2 的冻结 k=8。阈值是试验范围，不能称为模具安全间隙。

先在 H1–H7 下证明 P5 最小值，再固定该值探索候选：

- OPTIMAL 或独立复核的非负目标零值见证可以证明最小值。
- 正值 FEASIBLE 不等于最优；UNKNOWN 不等于无解。
- 当前实现未证明最优时跳过后续候选生成，报告未决状态。
- 已证明最小值大于零时允许输出硬合法的残余罚分方案；不能称每条残余 pair 都各自不可避免。

P5 是强试验偏好，不是 H8。P001 有 133 对混合 PRIORITY 关系，其中 94 对已有硬先后、17 对合法域无交集，有效 22 对均为翻孔—异形孔；已证明最小值为 0。两种折弯组合已纳入政策，但本件没有剩余可作用关系，不能据此验证其工艺收益。13 个缺几何动作持续标记覆盖不足。

### 4.3 次级目标：P1、P2 与合并后的 P3/P4

~~~text
S_secondary = 0.30 × P_area
            + 0.20 × P_extra_gap
            + 0.50 × P_group_fragmentation
~~~

| 分量 | 当前含义 |
| --- | --- |
| 面积排序 P1 | 面积显著相差超过 1.15 倍，且无任何硬先后直接/传递关系的 BEND pair；大面积反而先做记 inversion，同序不记；取 inversion 比例 |
| 额外间隔 P2 | H3/H4/H6/H7 来源按唯一有向 pair 去重；局部 capability/fixed/rank 合法组合给出 g_min/g_max，取 (g_actual−g_min)/(g_max−g_min) 的关系平均；上下界相同罚 0 |
| 合并拆散 | 启用配置中的 OperationType；BEND 按 SMOOTH/ROUGH 分组；完整 H1–H7 下证明 K_min/K_max，取 (K_actual−K_min)/(K_max−K_min)；无调整空间不参与；BEND 内先平均可调方向，再与其它可调类型平均 |

新流程不再将旧 FLANGING-only P3 与方向 P4 分别计权。边界基于 H1–H7，各组独立最小值不保证联合可达；P5 最优域若迫使额外拆散，必须披露取舍。

P001 的 FLANGING 为 [1,1]、SMOOTH 为 [3,3]，不处罚必要拆分；可调类型是 CIRCLE_PUNCH、IRREGULAR_PUNCH、BEND:ROUGH，均为 [1,2]。

权重入口为 configs/neighborhood_penalty_v02.json。0.30/0.20/0.50 尚未经过跨零件监督验证。SoftPenalty、P5、次级分数均不是 GNN label，也不意味着分数低就必然更优。原 D1–D3 仍是诊断；旧 G1 不进入无 reference 推理。

## 5. 64 个解、16 个方案与未来 Top-K

当前配置为池目标 64、选择 16、最多尝试 128 次。四个通道各目标 16 个：次级总分、合并拆散、额外间隔、随机分配成本。它们共享 P5 最优域，使用全局 no-good 去重，再独立复核评分。

选择先取次级分数最低 8 个，再保留尚未入选的最低拆散与最低间隔代表，最后按候选间 Hamming farthest-first 补齐。本次为 **8 个分数代表 + 1 个间隔代表 + 7 个多样性代表**。

64/16 是计算和人工审阅预算，不是可行解总数、最优样本量或监督充分性证明。随机目标不是均匀采样；逐次求解最优不等于全局质量最优的 64 个；16 个不是严格分数前 16。前 8 个可能很相似，需结合后续评审检查名额利用率。

当前 16 个用于内部审阅及评审准备。未来模型应对固定的完整候选池逐个评分，再取学习 Top-K，不能默认先用手工次级分数永久丢掉另外 48 个。若规模要求预筛，应另行配置和开发验证，不能无说明继承本次 16 名额。

## 8. 评审数据建设与标签政策

### 8.1 整体比较与独立挑战集

正式候选比较来自无 reference 池，既包含启发式低分方案，也保留不同拆散、间隔和分配结构。先固定候选，再组织专家比较，不按测试答案挑候选。

局部挑战比较在 H1–H7 下构造同序/异序或其它受控变化，用于观察启发式可能排除的安排。P5 较高的硬合法样本可在此出现，但不混入本轮 P5 最优集合。需要联动多个 Operation 时展示全部变化，不声称单因素；专家决定胜负。

旧局部对照工具已存在，但旧 k=5 采样不自动等于新版邻域挑战集。复用时需记录实际采样政策并检查覆盖，不静默替换历史比较。

### 8.2 历史评审的适用性

已审计旧 24 对为 18 个 D、6 个 A/B；6 个 A/B 全涉及 reference，仅 4 个 A/B 的双方都满足当前 H1–H7。这是监督覆盖不足，不是 24 个明确胜负样本。

保留原答案、比较方向及盲化映射。训练数据按规则版本复核完整方案，记录硬违规、重复和排除原因。针对当前硬合法候选排序的主训练/评价集采用双方硬合法的明确 A/B；不适用的历史比较另留审计。旧 R02 包保持暂停，新内部页不冒充已批准盲评材料。

| 原始答案 | 第一版训练处理 |
| --- | --- |
| A 更合理 | y=1 |
| B 更合理 | y=0 |
| C 基本等价 | 保留，暂不进入明确胜负损失 |
| D 双方有明显问题 | 保留问题反馈，不推断 A/B、平局或具体 pair 冲突标签 |
| E 信息不足 / 空白 | 不进入排序损失；分别记录无法判断与未完成 |

confidence 用于分层分析，A/B 第一版等权，1–5 不解释为正确概率。备注和问题定位用于审计，不自动变成约束或推理特征。多专家冲突原样保存，聚合规则另行明确。重复观察需去重或明确权重，不能虚增独立样本。

一条标签针对两个完整方案；不拆成逐 Operation 正确工序，不把整体胜负复制给每条邻域边，不用 penalty 或相似性补造标签。获胜方案不自动等于绝对可接受。

每批保存原始评审、左右方向、方案 hash、规则/生成版本、reviewer/batch 信息；报告有效 A/B、C/D/E/空白、唯一方案/比较数及覆盖缺口。

| 5 | P001、P002、P003、P004 | P005 |

同一件全部方案、对照和重复评审属于同一 split。每轮模型从头初始化，不使用见过本轮测试件的 checkpoint。零件才是跨零件评价单位，节点或候选数量不是独立零件数。

**P001 已用于规则、邻域、采样及软偏好开发，也已查看专家和评审。** 因此轮次 1 即使训练时隔离 P001 标签，也只能报告开发暴露零件上的留一结果，不能称为完全未接触的未知零件验证。五轮报告必须说明暴露，真正的前瞻泛化仍需未参与开发的新零件。重新封存文件不能消除既有暴露。

### 9.2 内层选择

每轮四个开发零件轮流三件训练、一件验证。限定小规模模型/正则化搜索，主要按零件平均成对损失选择，同时报告准确率和有效比较数。最佳轮数按预先配置规则汇总，再用四件从头重训。

生成预算、邻域阈值、P5 政策、次级权重和预筛如需选择，也仅用开发零件及内层结果。规则变更须另版生成、记录评审适用性，不能用外层专家调到满意。无有效验证标签不能产生虚构指标，须记录缺口并补审或调整实验可行性。

跨零件拟合的 scaler 等仅在训练 split 拟合；M2 仅依赖本件几何的归一化保持冻结。

### 9.3 轮次 1 如何处理 P001 专家

1. 专家方案、负载、评审不提供给生成与排名入口。
2. 用本件事实及开发侧确定的配置，独立生成候选。
3. 由 P002–P005 开发得到的模型对完整池评分。
4. 固定候选 hash、全量分数、排序、Top-K、模型和配置版本。
5. 独立 evaluator 再读取 P001 评价材料，或对固定结果开展盲评。
6. 不根据 P001 结果返回修改本轮模型、阈值、候选或推荐。

reference 可另作离线比较对象，不插入正式池或 Top-K。到 reference 的距离仅表示差异。第 9.1 节的开发暴露限制仍需披露。

## 10. 模型训练与待实现接口

### 10.1 表示及信息流

~~~text
本件事实与已确认元数据
  → H1–H7 + 版本化邻域/P5 + 候选探索
  → 独立复核、去重、固定完整候选池
  → 冻结 StaticPartGraph + 各方案 PlanOverlay
  → 同一训练好的评分器逐方案评分
  → 固定排序和学习 Top-K
  → 独立离线评价 / 专家盲评
~~~

目前完成到候选和内部审阅；tensor adapter、训练评分器和学习 Top-K 待实现。评价入口单独管理专家材料。

适配器保留 M2 节点、StationContext、既有关系及边属性。Graph2 已有几何距离、相对位置；PlanOverlay 已有 same_station、station_delta、abs_station_gap。不能只保留 adjacency 而遗漏这些属性。

新版 P5 邻域与冻结 Graph2 k=8 不一定覆盖相同 pair。训练前审计重点关系图边覆盖、动态属性、全件归一化是否表达相关尺度，以及缺几何限制。若有表示缺口，再另立版本化方案，不悄悄增加 Graph2 边或把 Sheet4/5 塞入冻结图。

Station 用本件局部/相对顺序和 capability；OP30 等字符串不作全局类别 embedding。Operation ID、part ID、盲号、生成通道、入选角色、reference 身份不作特征。第一版不输入 P5、次级总分或手工罚分分量，也不以它们作为标签。

### 10.2 学习目标

~~~text
s_A = Q_theta(StaticPartGraph + PlanOverlay(P_A))
s_B = Q_theta(StaticPartGraph + PlanOverlay(P_B))
loss = BCEWithLogitsLoss(s_A - s_B, y)
~~~

同一评分器共享参数。学习分数越高越偏好，与手工罚分越低越好的方向区分；损失输入分数差，不重复 sigmoid。分数用于同件相对排序，不解释成跨件绝对质量。

标注量不同时按零件平衡采样或使用等价损失权重，规则预先配置。模型不要求复现唯一 expert_station。D 的可接受性任务、C 的平局损失如需引入，另行设计，不自动扩展第一版。

### 10.3 基线与消融

| 方法 | 用途 |
| --- | --- |
| 固定 (P5, S_secondary) | 启发式对照，不制造标签；P5 最优池内由次级分数区分 |
| 简单方案特征学习模型 | 小模型基线；特征独立定义和泄漏检查 |
| Graph0 | 无 Operation 间消息传递的节点编码与 pooling |
| Graph1 | 冻结语义关系上的消息传递 |
| Graph2 | 冻结语义、几何关系及边属性上的消息传递 |

三图使用相同 split、候选、标签、指标和预算，尽量匹配容量并报告参数量。可在开发侧做动态几何边属性消融，检查局部对照表现；不改变存储图定义，不凭消融直接声称工艺因果。

宽度、层数、学习率、正则化和种子列表在实施时配置，由内层验证选择。目前没有已验证最优架构或超参数，旧文档的示例值不作为已完成决策。

## 11. 评价、验收与最终重训

### 11.1 分开评价生成和排序

- **生成覆盖：** 硬合法率、P5 证明状态、唯一数、通道数量、多样性、覆盖缺口、预算及候选不足；检查是否包含专家认可的选择。
- **评分器：** 真实 A/B 上的成对损失、准确率、分件样本数和种子波动；正式池与挑战集分别报告。
- **端到端推荐：** 模型和启发式在同一固定池上取 Top-K，再独立盲评。推荐质量来自真实判断，不来自手工罚分。

部分 pairwise 标签不等于完整真实排名；没有额外充分标注时，不构造虚假 NDCG、Spearman 或全局最优命中率。缺有效 A/B 的件不计算二分类准确率。

逐件报告再按件平均，附有效数及开发暴露说明；报告全部预设种子，不挑最好一次。高度相似变体限制泛化结论。利用外层结果继续改方法后，需要新零件前瞻验证。

### 11.2 持续验收

- 专家列缺失/更换不影响事实、约束、生成和模型输入；检查实际访问路径，不只比较两次输出。
- 未来评分与推荐仍需补齐隔离测试，输入/生成已验证不等于训练链自动通过。
- 记录种子、worker、状态、确定性与墙钟预算；墙钟超时可能受机器负载影响，不宣称只固定 seed 就严格确定。
- 不放宽规则凑数；最优未证、硬不可行、预算耗尽、可行域耗尽分开记录；不足 K 返回实际数和原因。
- 标签方向、完整分配、hash 可追踪；按件划分；模型不消费管理身份、专家分配或 penalty 标签。
- 冻结 Graph 和历史结果不回写；新规则、配置、评审、实验版本化；旧快照问题如实报告。
- 预测先固定，评价后读取；区分独立生成等于 reference 与人为离线插入 reference。

### 11.3 最终模型与产物

固定方法后，用五件全部适用真实评审从头重训，轮数由开发验证规则确定。P006 或之后新零件使用同一无 reference 入口；未来反馈进入下一版本，不自动改写已发布实验。

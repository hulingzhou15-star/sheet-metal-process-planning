# 邻域 penalty v0.2 设计：优先减少邻域同序，再比较其它偏好

日期：2026-10-16。

状态：设计已选定，尚未实现；本次只新增本文档。用户授权选择邻域方案并解释取舍。本文件不宣称新增生成器、评分器或新候选已经完成，不修改历史 N1、候选、专家数据及 Graph0/1/2。

## 1. 选择结论

采用分层软目标：

1. 满足 H1–H7。
2. 优先最小化 P5：指定外部邻域关系的同序罚分。
3. 在达到相同最优 P5 的方案中，优化其它软偏好，并保留候选多样性。

P5 不指定动作先后，不要求隔开多个工序，不指定 OP20/OP30；同序罚 1，异序罚 0。

新试验入口将 N1 的分序意图纳入 P5，不再同时添加那22对的硬性不同序条件。旧 N1 入口及结果保留为对照。该选择更新了之前“保留 N1 准入再叠加 P5”的建议，原因见下节。

这是具有最高软优先级的生成启发式：零罚分可行时不会被其它项抵消；零罚分不可行时允许输出明确标记的最小残余罚分方案。它不是新 H8，也不是物理干涉判定或可接受性保证。分层优先级本身是较强的试验偏好，需要跨零件验证。

旧 docs/LOCAL_PROCESS_PREFERENCE_LEARNING_PLAN.md 中“不启用固定邻近软惩罚”的阶段性决策，对本次独立 penalty 试验由本文更新；其中的新零件无专家输入、评价隔离、禁止自动制造标签等原则继续遵守。历史文档不回写。

## 2. 为什么现在改为分层目标

本次对已有 neighborhood_v01、最新16个 N1 候选及当前事实入口进行了只读核查。三种混合动作组合的 PRIORITY 外部邻域如下：

| 组合 | 优先邻域对数 | 硬先后已经分序 | 合法工序域无交集 | 仅由 N1 试验要求分序 |
|---|---:|---:|---:|---:|
| FLANGING–IRREGULAR_PUNCH | 22 | 0 | 0 | 22 |
| BEND–FLANGING | 43 | 41 | 2 | 0 |
| BEND–IRREGULAR_PUNCH | 68 | 53 | 15 | 0 |

此处硬先后包括传递关系；合法工序域使用 capability 和 fixed assignment。分类按 N1、硬先后、域无交集顺序记录，表中每对只计一次。它是明确的静态排除审计，没有声称进行了逐对完整可行性求解。

因此：

- 若继续强制 N1，这三类在当前候选中全部异序，P5 恒为0。
- 在仅 H1–H7 下，P5 当前有22对可作用的关系，正是原 N1 范围。
- 最新16个方案均满足 H1–H7 且22对全部异序，已经提供 P001 的 P5=0 可行见证。由于罚分非负，P001 的理论最小值为0；这不代表任何新生成器已经运行。
- 不为制造更多可排序分数而把所有邻域都判为同序有害。

采用分层软目标后，P5 在生成阶段排除可避免的同序安排。最终优选集合可能全部 P5=0，这是达成目标，不是分量失效。其余分量负责在这些方案间排序。

## 3. P5 的适用范围

使用现有 NeighborhoodContext，按完整 Operation 类型细分，不直接把宽泛的 CIRCULAR family 当作同一种工艺。

| 组合 | v0.2 处理 | 理由及证据边界 |
|---|---|---|
| FLANGING–IRREGULAR_PUNCH | 纳入 | 已有多组人工指出的同序问题；按通用几何条件选择，不写特定 ID |
| BEND–FLANGING | 纳入试验 | 两类成形动作局部接近，采用较保守的分序生成偏好；当前 P001 全部已由硬条件分开，尚未验证它在可同序情形下的有效性 |
| BEND–IRREGULAR_PUNCH | 纳入试验 | 局部切口与折弯的混合动作值得优先分开探索；当前 P001 同样全部硬性分开，不能据此声称得到新增专家验证 |
| BEND–BEND | 只观察 | 临近平行折弯与其它局部结构不能只靠距离认定不宜同序；贸然加入会直接对抗同方向集中偏好 |
| FLANGING–FLANGING | 只观察 | 相邻同类动作未必需要分序，缺少工具包络与明确案例支持 |
| IRREGULAR_PUNCH–IRREGULAR_PUNCH | 只观察 | 两个附近切口可能适合同序加工，不能从曲线距离直接判断 |
| 涉及 PRE_PUNCH / CIRCLE_PUNCH | 不纳入本版 P5 | 简单切孔和内部预孔关系没有统一分序偏好依据；保留原硬前置和邻域证据 |
| DIMPLE / BRIDGE 等其它类型 | 不启用 | 类型政策尚未确定，不自动归入相似类型 |

入选条件：

- 仅 EXTERNAL_NEIGHBOR；同组 PRE_PUNCH–FLANGING 内部关系不进入。
- FLANGING–IRREGULAR 必须由 FLANGING 发出的 PRIORITY arc 触发，与已验收 N1 方向一致。
- BEND–FLANGING、BEND–IRREGULAR 任一主动侧 PRIORITY arc 触发即可；保留触发方向，不重复计 pair。
- EXTENDED 本版不计罚，完整保留供审计；没有匹配不能解释为确认安全。
- 每个无向 Operation pair 在 P5 中只出现一次，且只属于一个细分类型。
- 已有任意方向的硬先后路径，或 capability/fixed 后合法工序域无交集，排除出计分分母并报告原因。此类关系必然异序，不重复奖励。
- 不因候选恰好异序、某批候选全部异序，或旧专家异序而删去关系。分母由事实和规则决定，对同一件的所有候选固定。
- 不自动删除“必须同序”的关系。若未来硬条件使它无法分开，保留罚分并报告不可避免性，避免把未解决问题藏成0。

## 4. 几何与阈值

沿用已建成的 v0.1 邻域，不在同一次试验同时改距离算法和计分政策：

- BEND–FLANGING：圆心到有限折弯线段，阈值为记录孔径的3倍。
- IRREGULAR–FLANGING：实际记录曲线最短距离，阈值为记录孔径的3倍。
- BEND–IRREGULAR：实际曲线最短距离，暂定10个源坐标单位。
- 相同 anchor/family/metric 内，首个有限正距离3倍跳变区分 PRIORITY / EXTENDED。
- 不强制5个邻居，不按长折弯全长度平均距离抹掉局部接近，不发明异形孔等效直径。
- 不增加距离衰减系数、角度罚分、采样接近长度罚分或 tool-clearance 假设。本版入选关系内等权。

3倍径和10源单位仍是试验范围，不是实际模具安全间隙。2/3/4倍径与5/10/15绝对范围只做敏感性比较，不用专家方案最优分数反推阈值。坐标单位必须满足现有输入契约，不能自动猜测或换算。

## 5. 数学定义和权重

令 E_t 为细分类型 t 通过上述条件后固定的计分 pair 集合。设：

```
v_e(P) = 1 if station(a) == station(b) else 0
p_t(P) = sum(v_e(P) for e in E_t) / len(E_t)
T = {t: len(E_t) > 0}
P5(P) = mean(p_t(P) for t in T)  if T is nonempty, otherwise 0
```

每个非空类型等权，类型内部 pair 等权。理由是避免某类关系因数量大而控制总分，并避免在没有数据时编造不同动作组合的严重程度倍数。报告必须同时显示各类型原始同序数和分母，不能只展示宏平均。

P001 当前有效类型只有 FLANGING–IRREGULAR，因此 P5=同序对数/22。旧75个候选中的同序数为4–15，平均9.4；据此设计公式的罚分范围为4/22–15/22。旧候选的正式新版本复评仍须在实现阶段保存独立报告，历史分数不覆盖。

P5 不与其它分量做可抵消的单一加权总和。候选偏好按二元组比较：

```
(P5, S_secondary)   # 字典序，均为越小越好
S_secondary = 0.30 * P_area + 0.20 * P_extra_gap + 0.50 * P_group_fragmentation
```

次级权重是此前试验建议0.15/0.10/0.25的归一化，不是训练结果；所有权重集中配置。该设计替代此前给 P5 分配0.50、其它项允许抵消它的提议。合并后的动作拆散分量依照独立新版本实现，旧 P3/P4 不静默改变。

为使次级目标可实施，合并拆散的分组固定为：默认启用当前schema中的各 OperationType；BEND内部按已有SMOOTH/ROUGH再分组，其它类型直接作为一个组。类型及方向列表配置化，未知类型或缺少方向报告不支持，不推测加工资源。每组在完整H1–H7可行域上证明K_min/K_max，使用 `(K_actual-K_min)/(K_max-K_min)`；上下界相同或本件没有该组时不参与平均。BEND先对其可调方向求平均，再与其它可调类型求类型平均，避免BEND因为有两个方向而天然获得双倍权重。没有可调类型时返回0并报告不适用。两个不同组的最小值不保证能同时达到，不能将它们独立最优值拼成一个虚构可行方案。

这些边界统一基于H1–H7，便于高P5挑战样本和低P5候选使用同一尺度；若优先降低P5迫使拆散增加，必须展示这一取舍，不能把残余拆散全部宣称为可以消除。P_area沿用v0.6的硬先后排除规则，P_extra_gap沿用唯一有向pair及局部合法gap归一化。本轮设计不同时修改P1的空间适用范围。

P5缺乏覆盖时虽然公式为0，界面和报告必须标记 `not_applicable` 或 `coverage_incomplete`，不能显示“没有邻近风险”。P5=0只表示本版已检查关系中无同序。

## 6. 求解、候选探索与排序

新入口只读取零件事实、版本化邻域政策和配置，不依赖专家、旧候选、具体问题 ID、盲号或专家负载。

1. 建立 H1–H7 可行性；不可行或未建立可行性分别报告。
2. 构建固定 P5 catalogue，保存纳入、排除、覆盖缺失及触发证据。
3. 在 H1–H7 下求 P5 最小值。各类型分母固定，使用约分后的精确有理数转整数目标；检查求解器整数界限，不静默浮点四舍五入。若数值规模不支持，返回明确配置/模型错误。
4. OPTIMAL 才称“最小值”；FEASIBLE 仅称“当前找到的最好值”，保留下界和 gap。若找到 P5=0，非负性本身足以证明全局最小。UNKNOWN 不当作无解或0罚分。
5. 证明最优后固定 P5=P5_min，再探索次级软偏好和多样性。未证明时允许输出内部暂存样本，但不自动制作正式评审包或声称不可避免残余问题。
6. P5_min>0时保留完整硬合法方案，报告“本试验偏好不能全部满足”。最小同序数量不可避免，不代表当前每一条残余pair都各自不可避免；逐pair不可避免性需要额外反事实求解。
7. 基线预算建议：64个唯一候选、最多128次尝试、选择16个；预算参数配置化，数量不足按实报告，不放宽已确定的最优 P5。
8. 为探索次级偏好，目标64个名额分为四个16名额通道：最小次级总分、最小合并拆散、最小额外间隔、随机分配探索；每通道在相同 P5 最优域内求解并去重。采用 no-good 后续求解可产生该目标下逐步变差但不同的候选。重复/耗尽不会复制凑数，未用名额可转入随机通道并记日志。
9. 选择16个时，8个按次级总分从低到高选择，另8个在剩余池中按原 Hamming farthest-first 补充。至少保留最低拆散和最低额外间隔代表：它们若未进入前8名，从后8名名额中先占位，重复代表只占一个名额。均为 P5 最优，不声称最后16个严格按同一分数优于所有落选方案。

次级目标中合并拆散的精确边界、分组及表达式应与新评分器一致；实施时如尚未完成，不能继续用旧 FLANGING-only 分量却把结果称为合并拆散已生效。

## 7. 每个推荐必须给出什么解释

解释依据真实计算记录，禁止生成没有证据的工艺理由：

- H1–H7是否通过；不通过者列出冲突，不进入软排序。
- P5各类型的适用pair数、同序pair、工序、几何距离、阈值、触发层级及证据来源。
- 与最接近的落选候选比较：P5差异、具体哪些关系变为同序/异序、所有连带动作移动。
- P5相同时，解释次级分量贡献；若因多样性入选，明确说明，不能假称总分更好。
- P5相同且次级分数相同，说明是稳定排序或多样性选择，不声称工艺有差别。
- 当前规则不能判断的组合、缺几何动作和未覆盖区域持续显示。

例子：某候选把O066/O200放在同一工序，其它条件相同时会增加P5；若存在P5=0的方案，该候选不会进入本轮优选集合。不能表述成“证明这两个动作发生模具碰撞”。

## 8. 为什么不采用其它方案

| 替代方案 | 本版不选的原因 |
|---|---|
| N1强制分序，再对同22对加软罚分 | P5始终为0，重复表达，不能说明它在生成中起什么作用 |
| 把P5以0.50加入普通加权和 | 允许其它收益抵消已指出的同序问题；大权重仍不是优先级保证 |
| 所有邻域都禁止同序 | 距离不足以证明干涉，且会阻碍合理的同类集中加工 |
| 所有207对同序都罚 | 把观察关系一律变成负面工艺假设，缺少类型区分 |
| 只罚距离最近的5个 | 会强行引入远邻、截断真实邻域，不符合现有几何设计 |
| 距离越近罚得越重，加入大量连续系数 | 当前没有工具包络或足够监督支持严重度曲线，零距离也不自动代表碰撞 |
| 继续只有诊断，等模型训练后解决 | 当前候选仍会重复已暴露问题，难以形成有效下一轮材料 |
| 用手写penalty制造A/B训练标签 | 只会让模型复制启发式，不能验证专家工艺偏好 |

## 9. 实施验收和实验边界

新增版本化配置、评分/生成模块、测试、审计和内部页面；旧定义、旧候选、原 Excel、reference 和盲映射保持不变。

必须覆盖：

- 当前 P001 catalogue 数量与22个有效pair精确可解释；缺几何和不支持类型不伪装成0风险。
- 原四组已知问题自动覆盖；新优选候选在已证明 P5_min=0 时均异序。
- 合成例子：P5低但次级分数差仍优先；P5相同才用次级分数。
- 合成例子：所有邻域同时分序无解时，H1–H7仍通过，输出正残余最优值及真实证明状态。
- 合成例子：BEND–FLANGING / BEND–IRREGULAR没有硬先后时确实产生P5作用；不将此测试当工艺验证。
- pair去重、方向触发、层级排除、类型宏平均、硬先后传递排除、工序域互斥排除、固定分母与[0,1]边界。
- 同一pair存在多个来源仍只计一次；UNKNOWN、超时、整数精度、候选不足不得隐式放宽。
- 所有候选独立复核；报告次级分量是否有变化、是否找到较少拆散的方案，不承诺P5最优域必然允许ROUGH集中。
- 新旧配置、输入、规则、求解状态及全部变更hash可追溯；专家列删除或改写不改变事实指纹和生成逻辑。

训练与评估：保留硬合法但P5较高的独立挑战样本，可用于训练零件的局部对照采集，但不混入本轮优选集合，不自动赋胜负。专家仍评完整方案。正式候选集合与挑战集分别评价，避免只测试被启发式预过滤的样本。P001属于开发暴露零件；权重/阈值只能用训练及内部验证零件调整，最终留出零件专家信息在预测固定后使用。

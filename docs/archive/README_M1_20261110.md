# P001 只读数据层（Milestone 1）

项目事实与研究路线以 [PROJECT_SPEC.md](PROJECT_SPEC.md) 为准。
本阶段仅实现 Excel 读取、静态数据对象和结构化校验。

Python 3.10+；运行依赖为 `openpyxl==3.1.5`。测试使用标准库 unittest。
在项目根目录执行：

```powershell
python -m pip install -r requirements.txt
python -B -m unittest discover -s tests -v
python -B -m src.data --output outputs/p001_validation.json
```

当前 Codex 已有可用 Python，可使用：

```powershell

& 'C:\Users\hulin\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -B -m src.data --output outputs/p001_validation.json
```

校验命令退出码：0 表示无 ERROR，1 表示数据校验失败，2 表示命令参数或文件访问错误。
不传 `--output` 时不保存报告。`--input` 可指定另一份同结构工作簿。
报告写入仅允许项目的 `outputs/` 或 `data/processed/`，会拒绝指向原始数据的路径别名。

```python
from src.data import load_excel, validate

data = load_excel("data/raw/钣金加工数据表_P001.xlsx")
report = validate(data)
assert report.passed, report.to_dict()
geometry = data.geometry_for(data.operations[1])
```

- `Operation` 只保存加工事实；`expert_station` 独立解析到 `ExpertReferencePlan`。
- `Geometry` 聚合同一 geometry_id 的 `GeometrySegment`，按既有 seq 排序，保留起点和有符号 sweep。
- ARC 的角度单位为度，正值逆时针、负值顺时针；BRIDGE 的 start/end 是 footprint 对角点。
- 空 surface_side 转为 `NOT_APPLICABLE`，单独的 `NONE` 能力值转为空集合。
- `ProcessGroup` 保存成员 ID；predecessor 和 CAD parent 提供不同类型的结构化关系。
- 原始行以 tuple 保留，重复 ID 不会在字典转换时被覆盖。诊断含 severity、code、entity_id、源 Sheet/行和 details。
- Loader 只读取原始文件快照，记录 SHA-256，以 read_only 模式读取数值和公式缓存，不保存或重算原始工作簿。
- 缺 Sheet、必需表头错误、非法数值或公式缓存缺失抛出 `WorkbookLoadError`，其 `.report` 仍为结构化报告。
- Validator 不修改对象，不根据专家方案或 CAD parent 发明工艺先后关系。
- 缺 Geometry 本身为 INFO；尚无确认规则的其他复合组类型为 WARNING，不直接判为非法工艺。

PROJECT_SPEC.md 尚未规定具体数值比较阈值。默认距离比较容差为 **0.001 个源坐标单位**，
可用 `--tolerance` 或 `validate(..., distance_tolerance=...)` 配置，报告记录实际值。
这是浮点数比较配置，不是制造公差，也不改变任何工艺硬规则。

检查范围包含标识与跨表一致性、Station 能力与顺序、专家参考分配、显式前置关系、
CAD parent 引用及循环、加工组配对、几何 seq、元素必需字段、异形孔连续闭合及整体逆时针方向、
ARC 有符号旋转与半径一致性，以及 BRIDGE 中心点。
使用解析有符号面积检查整体方向，不新增采样、CAD 对齐或自交判定假设。

本阶段不重新选择非圆孔轮廓起点，不创建 Graph、候选方案、优化器、模型、训练、数据库或 UI。
原有几何审核与修正脚本保留，本数据层不会调用这些可能修改工作簿的脚本。

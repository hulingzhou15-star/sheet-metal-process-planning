# 二维加工动作标注工具

P001 三维材料与局部工序回放：直接打开 `outputs/material_state_v01/P001/material_review.html`。
最新范围、测试与几何差异见 [MATERIAL_STATE_PROGRESS_V01.md](MATERIAL_STATE_PROGRESS_V01.md)。

## 标注流程

1. 缩放到目标区域，连续点选属于同一动作的图元。点击追加，再次点击取消；框选和“选同源子段”都追加并去重，空白处不清空。所有类型均可选择多条图元及多个独立轮廓。
2. 填写编号、名称、类型、表面侧、CAD 父动作及已有明确前置关系；预孔/翻孔加工组由脚本自动填写。点击“创建动作，录下一个”后自动清空选择和表单，进入下一动作；已创建动作的来源保持不变。编号用于当前零件内关联，内部 ID 用于稳定保存。
3. 点击“创建动作”仅记录类型、属性和来源；不选择技术性的几何生成方式，也不立即生成 Sheet2。已属于其它动作的图元会提示，确需共用时明确勾选确认。
4. 点击“保存标注”保存进度；关闭页面后可继续，亦可下载/导入 JSON 备份。标注未完成时允许保存，不要求几何规则均已支持。
5. 完成整图动作解释，勾选确认后点击“整理几何”。脚本按类型统一整理；断口、错选、待确认跨度、未定曲线规则分别报告。修改类型或来源后须重新确认并整理，旧结果不继续用于导出。
6. 设置并确认可支持的一般折弯影响区；填写或导入 Sheet3/Sheet4。使用“导出检查包”查看工作簿、几何记录、标注副本与问题清单。只有既有数据契约及 H1–H7 检查均通过才生成正式表。

“尚未处理”只表示来源片段尚无绑定、收纳或明确忽略记录；不表示每条片段都必须形成独立动作。预期动作数只是核对输入，不触发自动分组或补足数量。

点左侧已有动作才进入编辑模式，画布点选会修改该动作的临时选择。界面分别显示“本次已选”和该动作“已应用绑定”的数量；前者变化不代表已经修改项目中的绑定。此时要录入另一动作，先点“＋新建”；误加的临时选择可在切换弹窗中放弃。页头“保存标注”负责写入本地文件，不能把“已应用”误认为“已写入文件”。

左侧动作列表按创建顺序倒序显示，新动作在最上方；每次创建成功后列表自动回到顶部。搜索、类型筛选仍适用，编辑已有动作不会把它当成新创建。显示排序不改变项目 operations 数组、编号、工艺先后或导出顺序。

“明确前置动作”对应 required_predecessor_ids，填必须在当前动作之前且位于更早工序的动作编号。例如已确认 O003 异形孔须先冲、O020 才能折弯，则在 O020 中填 O003。不能只因距离近就填入。CAD 父动作仍按真实特征树记录。预孔与翻孔的先后已有 CAD/加工组规则表达，不必重复填写这一对；不能在预孔的前置字段误填翻孔编号。当前标注阶段未知关系可暂留空，后续确认，不由脚本补造。

加工组字段只读，自动识别依据为：一个 PRE_PUNCH 的直接 CAD 父动作是 FLANGING，且该翻孔只有这一个预孔候选。例如 O009 的父动作为 O008，脚本自动将两者归入 PG_O008。已唯一识别的自动配对统一使用 PG_翻孔编号，旧 PG001 会同步改为 PG_O008，保留同一对成员；修改翻孔编号时组号随之更新。读取时在内存中转换，用户保存标注时写入文件，不在用户录入期间额外改写项目版本。没有可靠 CAD 自动配对条件的旧明确组保留，不猜配对。对应动作尚未录入、多个预孔指向同一翻孔、既有组号冲突时显示原因；不按名称、距离、编号顺序猜配对，不倒置 CAD 关系。

选取几何时，画布会接收焦点并关闭 CAD 输入建议；候选列表仅在动作编号/名称清单变化时重建，避免已经选择父动作后仍反复弹框。当前填写的唯一 CAD 父动作会临时以蓝色高亮其已有图元，当前所选图元仍是橙色；切换、清空父动作或开始下一动作即更新/取消高亮。蓝色只是参考显示，不把父动作图元加入当前动作的绑定。

### 折桥

- 选择完整、轴对齐的外围矩形边界，统一整理后核对并确认外围范围，再整理。

### 异形孔

选择真实 LINE/ARC 闭合轮廓。整理时检查连接、分叉和重复，保留精确圆弧；多组轮廓分别保存。旧 Sheet2 的起始协议仍保留；无法自动满足时记录为适配待定，不新增起始规则。异形预孔/翻孔保留各自动作类型，不改成普通异形冲孔。程序不补造连接线。

### 拉包

同一个动作允许绑定内外多组闭合轮廓，各组保留独立 path_id 和原图元 ID。没有额外证据时，不自动认定顶部、底部或成形次数。内部圆孔不自动吸收；剖面和说明线可以明确标为背景。凸起侧单独填写“向光面 / 向毛面 / 尚未确认”，不从相机视角或表面侧自动推断。
